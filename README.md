# منصة MH للخلاصة الشهرية

لوحة عربية لإدارة الأرباح والمصروفات: تعديل الأرقام، اختيار السنة والعملة، استبعاد البنود المتداخلة، سجل الأشهر، المقارنة، النسخ الاحتياطي JSON، تصدير CSV، والطباعة إلى PDF.

نسخة جاهزة لـGitHub تبدأ بأرقام صفرية. لا تحتوي على أرقامك المالية أو إعدادات الاستضافة السابقة. لا تحتاج إلى بناء أو قاعدة بيانات.

## احتفظ ببياناتك أولًا

افتح المنصة السابقة واختر «تصدير ونسخ احتياطي» ونزّل ملف JSON إلى جهازك. بعد تشغيل الرابط الجديد استخدم خيار استعادة JSON من القائمة نفسها. الاستعادة تستبدل سجلات اللوحة الحالية بعد التأكيد؛ احتفظ بنسخة منها أولًا إن احتوت على بيانات مهمة.

البيانات تحفظ في المتصفح على جهازك. لا تنتقل تلقائيًا بين الروابط أو الأجهزة. لا ترفع ملفات النسخ الاحتياطية المالية إلى GitHub.

## رفع الملفات للمبتدئ بواسطة GitHub Desktop

1. نزّل GitHub Desktop من https://desktop.github.com/، ثبّته وسجّل الدخول بحسابك.
2. فك ضغط الحزمة؛ ستجد مجلد `mh-monthly-summary`.
3. في GitHub Desktop اختر **File → New repository**، واكتب اسم `mh-monthly-summary` واختر مكانًا جديدًا على الكمبيوتر ثم **Create repository**.
4. اختر **Repository → Show in Explorer** لفتح مجلد المستودع.
5. انسخ **محتويات** مجلد الحزمة إلى مجلد المستودع: `docs` و`tests` و`README.md` و`package.json` و`.gitignore`. لا ترفع ZIP نفسه، ولا تضع الملفات داخل مجلد خارجي إضافي.
6. ارجع إلى GitHub Desktop. اكتب وصفًا مثل `Add MH dashboard` ثم **Commit to main**.
7. اختر **Publish repository**. إبقاء **Keep this code private** يجعل السورس خاصًا. للنشر المجاني عبر Pages في حساب GitHub Free اختر مستودعًا عامًا بإزالة هذه العلامة؛ عندها يستطيع الجميع قراءة السورس.
8. اضغط **Publish repository** ثم **Repository → View on GitHub**. تحقق من وجود `docs/index.html` مباشرة داخل `docs`.

## تشغيل المنصة عبر GitHub Pages

رفع السورس وحده لا ينشئ رابط تشغيل. داخل المستودع افتح **Settings → Pages → Build and deployment** واختر:

| الخيار | القيمة |
| --- | --- |
| Source | Deploy from a branch |
| Branch | main، أو اسم الفرع الافتراضي الفعلي |
| Folder | /docs |

اضغط **Save**، وانتظر نجاح النشر في **Actions**، ثم افتح الرابط المعروض في **Pages**. شكله المعتاد `https://USERNAME.github.io/mh-monthly-summary/`؛ استخدم اسم حسابك والرابط الفعلي من الإعدادات.

حسب توثيق GitHub تتاح Pages مجانًا للمستودعات العامة، وتحتاج المستودعات الخاصة خطة تدعمها. رابط Pages يكون عامًا عادةً حتى لو كان السورس خاصًا. اللوحة لا تحتوي على تسجيل دخول؛ كل زائر يستخدم بيانات متصفحه المحلية ولا يقرأ سجلاتك من الخادم.

المرجع الرسمي: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## التشغيل محليًا

لا تفتح `index.html` بالنقر المزدوج؛ وحدات JavaScript تحتاج HTTP. إذا كان Python مثبتًا، افتح Terminal في مجلد المشروع ونفّذ:

```bash
python -m http.server 8000 --bind 127.0.0.1 --directory docs
```

على Windows يمكن استعمال `py` بدل `python`. افتح `http://127.0.0.1:8000`، ولإيقاف الخادم اضغط Ctrl+C. هذه الخطوة اختيارية؛ Pages يكفي للتشغيل.

## كيف أعدّل؟

| الملف | وظيفته |
| --- | --- |
| docs/index.html | الاسم والنصوص والأزرار وأقسام الواجهة |
| docs/style.css | الألوان والتنسيق والهاتف والطباعة |
| docs/assets/mh-logo.png | الشعار؛ استبدله بصورة بالاسم نفسه |
| docs/app.mjs | التفاعل والحفظ والتصدير والاستعادة |
| docs/model.mjs | بنود الحساب والمبالغ والتحقق |
| tests/model.test.mjs | اختبارات بأرقام تجريبية |

استعمل Visual Studio Code للتعديل. بعد الحفظ ارجع إلى GitHub Desktop: اكتب وصف التغيير، اختر **Commit** ثم **Push origin**. سيُعاد نشر Pages تلقائيًا إن كانت مفعّلة.

المبالغ مخزنة كأعداد صحيحة بوحدة جزء من ألف لتجنب أخطاء جمع الكسور. تغيير أسماء البنود أو بنية JSON يحتاج خطة لترحيل البيانات السابقة.

## الاختبارات

باستخدام Node.js إصدار 22 أو أحدث، نفّذ من مجلد المشروع:

```bash
npm test
node --check docs/app.mjs
```

لا تحتاج إلى `npm install`. اختُبرت الحسابات والمدخلات والاستعادة والبداية الصفرية. افحص أيضًا الواجهة والطباعة في متصفحك بعد النشر.

## حل المشكلات

- **404:** تحقق من `main /docs` ووجود `docs/index.html` ونجاح النشر في Actions.
- **Pages غير متاح:** راجع صلاحيتك وخطة الحساب وخصوصية المستودع.
- **بياناتي لا تظهر:** الرابط أو المتصفح تغير؛ استعد JSON المحلي.
- **التعديلات لا تظهر:** نفّذ Push، وانتظر نجاح النشر ثم حدّث الصفحة.
- **لم أحتفظ بنسخة:** افتح الرابط القديم في المتصفح نفسه وصدّر بياناته قبل مسح بيانات المتصفح.
